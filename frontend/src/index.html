评分口径与数据说明

“全球评分”汇总目前接入的五个动画社区，代表这些平台的评价，不代表所有国家或全部观众。

全部评分换算为十分制。默认权重为 Bangumi 5、MyAnimeList 2、AniList、Filmarks、Anikore 默认关闭；你可以自行调整。某个平台暂无评分时，综合分仅使用其余有效平台的权重。权重为 0 的平台仍显示评分，但不参与综合分。

平台评分人次为各站投票数之和，无法跨站去重。综合分未做样本量校正，可使用平台覆盖与评分人数筛选判断可靠性。

Filmarks 与 Anikore 使用作品页的五星均分，换算为十分制；Anikore 的百分制综合热度不参与计算。

AniList 取 meanScore 和 averageScore 的均值。排名以未四舍五入到两位小数的综合分排序，同分并列；不同权重下的榜单应分别比较。

历史数据从实际采集时开始记录，不回填、不虚构。7d / 30d 使用每小时最后一次真实记录，90d / 1y 使用每日最后一次真实记录。平台采集失败时，趋势中的缺失数据不会补成旧分数。

后台在服务运行期间每小时采集当季番剧和查看过详情的作品。数据缓存与历史保存在本机数据库，关闭浏览器不影响采集；停止后端服务期间不会产生记录。
